cluster-design

The design of a computer cluster as formulas with units: the fit of the parts, the capacity, the watts, the heat, the noise and the load of each circuit.

Check a machine

Choose the parts of one machine. Each fit rule is a Vex program. The library checks the machine in your browser at each change.

The measures

Each value is a Vex program over the parts. Each watt from the wall becomes heat in the room.

        How it works

        1. Parts are data. A table gives the fields of each class. Each amount has a unit, so a cooler height of 16 cm and a cooler of 155 mm compare correctly.
        2. A design is a tree. The cluster has machines, and each machine has part lines. The tree holds each amount in the unit of its field.
        3. A rule is a program. Each fit rule is a Vex program at a machine. A rule that cannot read a part gives no read, not a pass.
        4. A measure is a program too. The power, the heat, the noise and the CI runner slots are Vex programs over the same tree. The rule of the power supply reads the program of the power, so the two always agree.
        5. A site is input data. A site record gives the circuits, the rooms and the price of electricity. The rules of the site read the same programs of the power at each machine of a circuit or a room.
        import { checkDesign, overall, readCatalog } from "@mark1russell7/cluster-design";

const catalog = readCatalog(parts);
const result = checkDesign([{ id: "node-1", lines }], catalog.value);
overall(result.findings); // "fits", "breaks" or "unread"
